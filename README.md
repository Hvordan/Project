# Таємні знаки Еквестрії

Україномовна командна браузерна гра за мотивами «Кодових імен» у стилі My Little Pony. Для однієї партії потрібно 4–12 гравців. Капітани команд Селестії та Луни бачать ключ до поля. Розвідники розкривають картки за підказками. Відкрити Дискорда означає одразу віддати перемогу іншій команді.

## Запуск у VS Code

Потрібна Node.js 22.13 або новіша. Проєкт перевірено на Node.js 24. Перевірити свою версію можна командою `node -v`.

1. Розпакуй архів. У VS Code вибери **File → Open Folder** і відкрий папку `equestria`, у якій лежить `package.json`.
2. Відкрий **Terminal → New Terminal**. Виконай команду для встановлення залежностей.

   ```sh
   npm ci
   ```

3. Запусти сервер.

   ```sh
   npm start
   ```

4. На цьому комп’ютері відкрий [localhost:3000](http://localhost:3000). У терміналі лишається запущений сервер. Щоб його зупинити, натисни **Ctrl+C**.
5. Для гри з телефонів підключіть пристрої до однієї Wi-Fi мережі. На телефонах відкрийте адресу комп’ютера, яку сервер вивів після «У спільній Wi-Fi мережі». Наприклад, `http://192.168.1.20:3000`. Якщо macOS або Windows запитає про доступ для Node.js, дозволь локальні підключення для цієї мережі. Гостьові або університетські мережі іноді ізолюють пристрої. У такому разі скористайтеся спільною домашньою мережею чи точкою доступу.
6. Для розробки є команда `npm run dev`. Вона перезапускає Node.js після змін у серверних модулях. Після редагування фронтенду онови сторінку.

Адреса `localhost` на телефоні вказує на сам телефон. Для гри з різних мереж потрібен опублікований Node.js-сервер із підтримкою Socket.IO та постійним місцем для файлу SQLite. Цей архів містить повну локальну версію. Збірка фронтенду чи окремий сервер бази даних для неї не потрібні.

## Перша партія

1. Один гравець вводить ім’я та створює кімнату. Він стає ведучим. Інші відкривають сайт і вводять свої імена та п’ятисимвольний код у вкладці **Приєднатися**.
2. У кожній команді обирають капітана й хоча б одного розвідника. Якщо вас п’ятеро, грайте складами 2 і 3. Ведучий теж може зайняти будь-яку з ролей. Учасник, який не обрав роль до старту, спостерігає.
3. Капітани обирають магію. Ведучий може змінити колоду та тривалість ходу. Після вибору натискає **Зберегти налаштування**, потім **Почати гру**.
4. Капітан активної команди вводить одне слово і кількість пов’язаних карток. Розвідник обирає картку та підтверджує відкриття. Усі підключені пристрої отримують результат. Спільний чат бачать обидві команди.
5. На свою картку команда може відповісти ще однією спробою в межах ліміту. Нейтральна або чужа картка, пас чи закінчення часу передають хід. Команда, усі картки якої відкрито, перемагає. Дискорд завершує матч одразу.
6. Коли партія закінчиться, ведучий натискає **Зіграти ще раз**. Повернення до лобі збереже гравців і дозволить змінити ролі й колоду.

**Демо на одному ноутбуці.** Відкрий адресу вручну в чотирьох нових вкладках і зайди під різними іменами. Для такого демо ролі розподіляються як на чотирьох пристроях. Команда браузера «Дублювати вкладку» може перенести на нову вкладку сесію попереднього гравця.

## Правила магії

- **Твайлайт** додає ще одне слово до поточної підказки. Застосовується після основної підказки, поки триває відгадування. Кількість спроб залишається тією самою.
- **Флаттершай** відкриває одну випадкову нейтральну картку у свій хід. Команда зберігає хід і кількість спроб.
- Магію використовує капітан лише один раз за партію. Обидві команди можуть обрати одну й ту саму поні.

## Власні колоди та збереження

Відкрий **Колоди → Створити колоду**, введи назву і 25–160 різних слів, кожне з нового рядка. У лобі ведучий може обирати вбудовані й власні колоди. Після вибору кімната зберігає копію списку слів, тому редагування або видалення колоди не змінює вже вибраний набір. Щоб застосувати відредаговану версію, ведучий-автор ще раз натискає **Зберегти налаштування** в лобі.

Сервер сам створює файл `data/equestria.sqlite`. Там зберігаються кімнати, гравці, перебіг партії, останні 80 повідомлень та авторські колоди. Ключ автора колод зберігається в локальному сховищі цього браузера. Ігрове місце прив’язано до сесії вкладки. Оновлення сторінки або короткий обрив зв’язку зберігають роль. Після явного виходу учасника команди під час гри кімната повертається до лобі. Якщо ведучий втратив з’єднання, інший учасник може взяти його роль кнопкою **Стати ведучим**.

## Код і розподіл між п’ятьма учасниками

| Ділянка | Файли | Що показати на захисті |
| --- | --- | --- |
| Ігрове поле та оформлення | `public/room.js`, `public/style.css`, `public/art/` | Два різні види поля, відкриття картки, планшетна й мобільна верстка |
| Вхід, лобі й командні ролі | `public/main.js`, `public/ui.js`, функція `lobbyPage` у `public/room.js` | Приєднання за кодом, зайнята роль капітана, автоматичне повернення після оновлення |
| Правила гри | `server/game.js`, `test/game.test.js` | Генерація 25 карток, перевірка підказки, дві здібності, перемога й таймер |
| Сервер і синхронізація | `server/index.js`, `server/app.js`, `test/server.test.js` | Socket.IO передає кожному учаснику його версію поля. Сервер перевіряє кожен хід |
| Колоди й база | `server/decks.js`, `server/store.js`, редактор у `public/ui.js` | Три тематичні набори, створення своєї колоди, запис у SQLite та відновлення |

Клієнт використовує JavaScript-модулі, HTML і CSS. Express віддає сторінки, ресурси та HTTP API колод. Події Socket.IO обробляють вхід і дії у кімнаті. Сервер спочатку перевіряє дію, потім зберігає стан у SQLite й надсилає кожному клієнту доступні для його ролі дані. Шрифти та ілюстрація входять до архіву й завантажуються локально.

## Тести

```sh
npm test
```

Модульні перевірки охоплюють розподіл карток, доступ за ролями, підказки, обмеження кількості спроб, таймер, перемогу та обидві здібності. Інтеграційні тести запускають окремий сервер, підключають чотири клієнти Socket.IO, грають до завершення, перевіряють повторний вхід, відновлення після перезапуску і редактор колод. Робоча база користувача не використовується тестами.
